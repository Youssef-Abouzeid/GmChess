# ♛ Chess Overlay Engine

A transparent, always-on-top Python overlay that reads your chess.com board via
computer vision and draws Stockfish best-move arrows directly on the screen.

---

## Architecture

```
chess_overlay/
├── main.py           ← Entry point
├── config.py         ← All tunable constants (window size, thresholds, paths)
├── vision.py         ← Screen capture + OpenCV template matching + FEN builder
├── engine.py         ← Stockfish wrapper + human-like error injection
├── overlay.py        ← Tkinter transparent window + arrow rendering + sidebar
├── calibrate.py      ← Visual alignment tool (run before main.py)
├── create_assets.py  ← Generates piece template PNGs
├── requirements.txt
└── assets/           ← Piece PNG templates (generated by create_assets.py)
    ├── wP.png  wN.png  wB.png  wR.png  wQ.png  wK.png
    └── bP.png  bN.png  bB.png  bR.png  bQ.png  bK.png
```

**Thread model**

| Thread | Responsibility |
|--------|----------------|
| Main (UI) | Tkinter event loop, canvas drawing, sidebar controls |
| VisionLoop | `mss` screen capture → template matching → FEN strings |
| EngineWorker | Stockfish analysis → `MoveResult` callbacks |

All cross-thread communication uses `root.after(0, callback)` for UI updates
and `queue.Queue` for the engine request queue.

## Installation

### 1. Prerequisites

- Python 3.11+
- Windows 10/11 (required for transparent overlay + click-through)
- [Stockfish](https://stockfishchess.org/download/) binary

### 2. Python dependencies

```bash
cd chess_overlay
pip install -r requirements.txt
```

### 3. Stockfish path

Open `config.py` and set:

```python
STOCKFISH_PATH = r"C:\path\to\stockfish.exe"
```

## Setup workflow (first run)

### Step 1 — Generate piece templates

**Option A: Auto-download (recommended)**
```bash
python create_assets.py
```
Downloads the standard Neo piece set from Wikimedia Commons at 118 px.

**Option B: From screenshot**
```bash
# Take a screenshot of chess.com at your usual zoom level, then:
python create_assets.py --from-screenshot my_screenshot.png
```
An OpenCV window opens; click the board's top-left and bottom-right corners.
The script exports all 64 squares to `assets/_squares/` for manual labelling.

**Option C: Simple fallback (no internet)**
```bash
python create_assets.py --simple
```
Renders Unicode chess glyphs with PIL — quick but lower detection accuracy.

### Step 2 — Calibrate overlay position

```bash
python calibrate.py
```

- A coloured 8×8 grid appears.  Drag it or use **arrow keys** to align it
  precisely over the chess.com board in your browser.
- Press **S** to save the position to `calibration.json`.
- The main overlay reads `calibration.json` on startup.

> **Tip:** Use the chess.com board at 100 % browser zoom for best results.
> The default board size targets 950 × 950 px — match this in chess.com
> settings (Board → Size).

### Step 3 — Run the overlay

```bash
python main.py
```

| Setting | Description |
|---------|-------------|
| Skill Level (0–20) | Maps to Stockfish UCI_Elo (500–2500). 20 = full strength |

## Computer vision details

**Template matching pipeline**

1. `mss` captures the board region at 2 fps (configurable via `VISION_FPS`)
2. Each of the 12 piece types is matched at 5 scales: `[0.8, 0.9, 1.0, 1.1, 1.2]`
3. All hits above confidence threshold `0.65` are collected
4. Non-Maximum Suppression (IoU threshold `0.2`) removes overlapping boxes
5. Each surviving detection is mapped to an 8×8 grid cell
6. A FEN string is constructed and validated with the `chess` library
7. Changed positions trigger a new Stockfish analysis request

**Improving detection accuracy**

- The `--size` argument in `create_assets.py` should match your actual square
  size in pixels (default 118 px = 950 / 8)
- Disable browser extensions that alter page appearance
- Use the chess.com "Wood" or "Classic" board theme — these match the
  Wikimedia piece art best
- Avoid animated piece movement (disable in chess.com board settings)

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| `Stockfish not found` | Set `STOCKFISH_PATH` in `config.py` |
| No arrows appearing | Run `calibrate.py` to align the board region |
| Arrows on wrong squares | Re-check calibration; ensure browser zoom is 100 % |
| High CPU usage | Reduce `VISION_FPS` in `config.py` (e.g. `1`) |
| Pieces not detected | Re-run `create_assets.py` at correct `--size` |
| Click-through not working | `pywin32` must be installed; run as admin if needed |
| `transparentcolor` flash | Normal on Windows — avoid rapidly moving the window |

## Detection threshold tuning

In `config.py`:

```python
CONFIDENCE_THRESHOLD = 0.65   # lower → more detections (more false positives)
IOU_THRESHOLD        = 0.2    # lower → stricter duplicate removal
SCALES               = [0.8, 0.9, 1.0, 1.1, 1.2]  # add 0.7 or 1.3 if needed
```
